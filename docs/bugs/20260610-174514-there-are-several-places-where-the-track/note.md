There are several places where the tracks UI is too busy. If a layer is selected, we don't need buttons in each of the cells. If it is something like note repeat 1/8 the whole cell should be the toggle. When marked as "on" it needs to write the point at which it was turned on (the step that will be repeated) and the value for how it is repeated. When it is turned off, the values are reset. There are probably other instances of this on the phrase page too.
