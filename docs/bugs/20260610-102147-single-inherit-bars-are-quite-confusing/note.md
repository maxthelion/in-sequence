Single, inherit, bars are quite confusing modes for phrase cells. The modal that opens to show the options for a cell doesn't have a cross to close it. The idea is that most of the editing of the values of the cells happens in the main view. Eg volume should be an interface that can be dragged, like velocity on the step sequencer. We need to apply these concepts consistently. The general rule is that values that are booleans are just either single or per bar. Same for program change. Values like volume can be different per bar, single, or ramped etc. "Inherit" isn't something that can be set for a cell unless it is following a cell with a value set. There are more optimisations to be made here
