# Process Health Warning Signs Pass

Run one process health observation pass using the new warning-sign README.

Focus on whether the loop is converting agent effort into showable, reviewed
product progress. Look at builder throughput, review follow-through, observer
outputs, coordinator decisions, stale or duplicate handoffs, actor logs, and
whether any environment/tooling problems are slowing product work.

Update `docs/multi-pass-coordinator/coordinator/process-health.md` and write a
coordinator inbox note if a process decision or process-improvement request is
needed.
