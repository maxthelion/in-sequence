# Current Work

Each file here is one active thing the loop is trying to move toward showable
product quality.

A work item may be a feature, lane, slice, probe, branch, or overnight build
target. It should be concrete enough that agents can build, review, and rework
it, but broad enough that the coordinator can see why it matters.

The work observer keeps these files honest. The coordinator uses them to decide
which build, review, rework, PM, or product-owner request should happen next.
