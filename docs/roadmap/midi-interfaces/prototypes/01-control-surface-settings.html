State A — Disabled (initial)
Toggle: OFF
Pickers: greyed out
Status: "Not enabled"
Test LEDs: disabled
Hardware: untouched (Live mode)
State B — Enabled, no endpoints
Toggle: ON
Pickers: active, both at "— Select —"
Status: "Endpoints not configured" (warning)
Test LEDs: disabled
Hardware: still untouched
State C — Enabled, input only
Toggle: ON
Input: selected
Output: not set
Status: "Output required for LED feedback" (warning)
Test LEDs: disabled (output needed)
State D — Connected
Toggle: ON
Both endpoints: selected
Status: Connected
Test LEDs: enabled
Hardware: Programmer mode active, surface rendering workspace state
State E — Device missing
Toggle: ON, endpoints saved
Saved endpoint not in current list
Status: Device not found
Test LEDs: disabled
Picker shows saved name in italic + "(not found)"
