Prototype: Clip History — Inline Drawer (v2)
Approach: Clip History expands as an inline drawer within the source editor pane — no modal overlay. The user stays in context.
  • Interaction budget: open drawer in 1 click; select+audition in 2; save in 1 = 4 total. Same as v1.
  • Key strategic difference from v1: no focus-trap, no overlay — user can see the slot palette and the generator params simultaneously with the history.
  • Trade-off: vertical space is constrained, history strip is more compressed. Modal (v1) gives more room.
  • States: generator view → drawer open (no selection) → bar selected + auditioning → slot chosen → overwrite warning → saved.
