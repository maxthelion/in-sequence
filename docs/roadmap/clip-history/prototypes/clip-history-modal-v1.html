Prototype: Clip History — Modal Flow (v1)
Approach: a dedicated Clip History modal opened from the generator panel.
  • Interaction budget: open history in 1 click; select+audition in 2 more; save in 1 more = 4 total.
  • Path under test: generator view → open modal → select bar(s) → audition virtual clip → choose slot → save.
  • States reachable via nav buttons below: Default (no selection), Bar Selected + Auditioning, Save Slot Chosen, Overwrite Confirm, Empty History, Successful Save.
