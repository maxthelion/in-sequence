# Global Layer Perform Mode

A button on the Tracks page (perform mode) that swaps the per-track cards
for a matrix of the perform layers themselves — the same cell grammar as
the layer selector. Touching a layer cell applies that layer to ALL
tracks: mute silences everything, note repeat 1/16 engages on every
track, etc.

Raw intent: `docs/roadmap/intent.md` § 2026-06-11 Global Layer Perform
Mode. Builds directly on the perform-layer machinery (fan-out exists for
the drum-group pattern row and recipientTrackIDs already supports
multi-track application).
