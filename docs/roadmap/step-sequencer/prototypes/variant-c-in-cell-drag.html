Interaction Contract (Variant C)

  • Left-click on inactive cell: toggle ON
  • Left-click on active cell: toggle OFF
  • Right-click (or Shift+click in this mockup): select / deselect step — amber border appears, batch bar shown
  • Drag up/down on a value-layer cell: change bar height (velocity / chance) — no panel opens
  • Left-click on an option-layer cell (slicer / chord): cycles through options
  • Escape: deselect all
  • Interaction budget: Edit a step value in <=2 interactions: (1) click layer tab → (2) drag bar inside cell.
