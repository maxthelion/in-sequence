Interaction Contract (Variant D)

  • Left-click inactive cell: toggle ON (trigger layer)
  • Left-click active cell: toggle OFF (trigger layer)
  • Right-click / Shift+click: select / deselect step — amber border
  • On selection: layer-tab row transforms into rotary controls (one per layer)
  • Drag up/down on rotary: adjusts that layer's value on ALL selected steps
  • On deselection (all steps cleared or Escape): row reverts to tabs
  • Drag up/down on cell bar: still works for single-cell edits (same as Variant C)
  • Option layers (slice / chord): rotary snaps to nearest integer index, cycling through options
  • Interaction budget: multi-step layer edit in <=3 interactions: (1) Shift+click steps → (2) rotary row appears → (3) drag rotary.
