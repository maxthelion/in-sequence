Prototype annotations (Variant A — Right-Side Master Column):
  • MODEL GAP: MasterBusScene.outputGain is clobbered to 1.0 by normalized() (MasterBus.swift:301). A user-controllable master fader requires a new MasterBusState.masterOutputGain field or a targeted normalization fix. Spec must flag this as a prerequisite.
  • EXTRACTION NEEDED: The inline crossfader widget is a private func at ScenesWorkspaceView+Perform.swift:28–72. It must be extracted into a standalone MasterCrossfaderView before it can be embedded here.
  • NEW CAPABILITY: Metering requires a new installTap on finalOutputMixer, publishing peak values to the main thread via the publishToMain pattern (EngineController.swift:163). No metering tap exists anywhere in the codebase today.
  • ENGINE LIFECYCLE: The metering tap must be removed before engine stop and reinstalled after restart (MainAudioGraph.swift:88–145 stops/restarts on graph rebuilds).
  • INSERT SCOPE: Inserts shown are scene-scoped (active scene), matching the existing model. The section label makes this explicit ("Inserts (Scene: …)"). A global post-crossfade chain would require new model work.
  • STUBS: Track channel strips and bus sections are off-path and rendered as dashed-border placeholders.
