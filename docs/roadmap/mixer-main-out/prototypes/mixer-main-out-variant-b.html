Prototype annotations (Variant B — Top Master Section):
  • LAYOUT CONCERN: Horizontal fader (shown here) has shorter throw than a vertical fader of the same pixel budget, reducing precision for small gain adjustments. Variant A's vertical fader is better suited for the master channel. Reviewers should weigh this against the discoverability benefit of the top band.
  • HORIZONTAL METERING CONCERN: Horizontal meter bars are less readable at a glance than vertical bars for level monitoring (conventional DAW practice uses vertical). The top band forces a horizontal orientation that may reduce the value of the meter.
  • MODEL GAP: MasterBusScene.outputGain is clobbered to 1.0 by normalized() (MasterBus.swift:301). Spec must flag the model fix as prerequisite for a user-controllable master fader.
  • EXTRACTION NEEDED: The inline crossfader widget is a private func at ScenesWorkspaceView+Perform.swift:28–72 and must be extracted into a standalone view.
  • NEW CAPABILITY: Metering requires a new installTap on finalOutputMixer publishing via publishToMain (EngineController.swift:163).
  • INSERT SCOPE: Inserts shown are scene-scoped (active scene), matching the existing model.
  • STUBS: Track channel strips and bus sections are off-path, rendered as dashed-border placeholders.
