What This Solves Better

The selection set remains obvious even when track rows are dense. It also gives the latch mode a natural home beside the shared controls. A user can glance at the sidecar before committing a change and know exactly which tracks will be touched.

Trade-Off

The notes explicitly lean toward direct matrix editing for v1. This variant adds clarity, but it moves the primary edit off the row the performer is touching. That makes it safer, not faster.
