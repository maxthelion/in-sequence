Why This Direction

This keeps the v1 rule literal: the performer makes an edit on a real cell, and every selected track receives that same value immediately. There is no side inspector or modal on the happy path.

  • Row-level selection state stays adjacent to the cells it will affect.
  • Fill and Repeat share one latch switch, which avoids per-control drift.
  • Unselected rows remain visible, so the blast radius of a linked edit is legible before the click.
