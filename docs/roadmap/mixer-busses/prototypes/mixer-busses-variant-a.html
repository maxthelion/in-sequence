Prototype annotations (Variant A — Bus Column Section):
  • SPEC Q1 — Solo convention: This prototype implements exclusive solo (one strip soloed at a time, all others dim). Additive solo (multiple strips can be soloed simultaneously) is the alternative. The convention must be confirmed before implementation — it affects the solo state-machine in EngineController.
  • SPEC Q2 — Bus output selector: Bus strips show a static "→ Master" label, not a dropdown. If bus-chaining is ever introduced, this becomes a dropdown. User-stories §2 says master-only; prototype matches. Confirm this is not a short-term need.
  • SPEC Q3 — Routing change visual: Selecting a new bus from a track's output selector triggers a 600 ms "Applying…" disabled state on that strip. The real graph stop/rewire/restart (see existing-state.md §2) takes ~50–200 ms. The prototype overstates the duration for visibility. Decide: (a) no visual; (b) brief disabled state (shown here); (c) toast only; (d) modal. The stop/restart must happen on the main thread.
  • SPEC Q4 — Bus insert scope: Prototype treats bus inserts as global (not scene-scoped). Master inserts today are scene-scoped (per MasterBusScene). Bus inserts could be global or also scene-scoped. User-stories do not specify — confirm before implementation.
  • COMPONENT GAP (bus inserts): No generic insert-chain component exists in production code. ScenesWorkspaceView insert UI is coupled to MasterBusState/MasterBusInsert. Implementation loop must decide: extract generic component or duplicate. Prototype shows the desired shape without claiming the component is shared.
  • SOLO — new capability: No solo button exists anywhere in production today. The solo logic (muting non-soloed buses and tracks routing directly to master) is a new state machine in EngineController. This is non-trivial.
  • NAMING: Inline rename on double-click shown for both track and bus strips. Production pattern exists for MasterBusScene names. Track strips currently do not support inline rename — confirm whether this rename should also land on track strips as part of this item or is deferred.
  • STUBS: Master Out column, FX picker modal, insert parameter editors, scene crossfader, undo are all dashed-border stubs.
  • EMPTY STATE (Leads Bus): Visible in "Empty Bus State" scene. Shows "No tracks routed here" badge inside the insert section. The bus is still controllable (fader, mute, solo) even with no inputs — this is intentional and consistent with DAW conventions (a bus can exist before tracks are routed to it).
