Prototype notes

  • Primary question: does placing the send bus editor in the same surface as the master bus editor (left sidebar + chain area) feel natural, or does it belong inside the mixer channel strip panel?
  • Send A starts populated (Reverb + Delay) to test reorder/bypass/remove affordances. Send B starts empty to test the empty-state path.
  • The → Master output (auto) label beside the chain title communicates Story 3 (return is always active) without requiring a separate control.
  • Drag handles (≡) are shown but dragging is not implemented — this tests whether the affordance is legible before implementing it.
  • Open question: should bypass toggle per insert be a checkbox, a button, or a colored LED? Currently it is a text button that turns yellow when active.
  • Open question: should the effect picker be inline (as shown) or a modal sheet? Inline keeps context but may crowd the chain editor.
  • Architecture note from existing-state: MasterBusInsert types exist but are named master-specific. The insert chain UI would need to be extracted into a generic component to reuse here.
