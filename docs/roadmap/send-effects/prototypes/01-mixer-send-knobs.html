Prototype notes

  • Primary question: does a per-track A / B knob pair in the channel strip read clearly without crowding the strip?
  • The knobs are placed below the mute button and separated from the fader by a horizontal rule — does this grouping feel right?
  • Send bus columns (far right, dashed border) are stubs — see Prototype 02 for the insert chain editor.
  • Adversarial fixtures used: long Unicode track name, a muted track with full sends, tracks with mixed zero/non-zero send states.
  • Non-zero send values shown in blue to distinguish active routing from zero (off). Consider whether a zero-value knob should look visually inert.
  • Interaction budget: set a send level in <= 2 interactions — click knob, drag slider.
  • Open question: should the send knob be a compact rotary (shown) or a mini horizontal fader? A fader might be more touch-friendly on iPad.
  • Open question: should a "0%" send knob be greyed out or identical to an active one? Currently both look the same except the value label color.
