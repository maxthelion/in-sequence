The lane tabs remain authoring controls. The header toggle is separate so the user can hear fill without implying a document edit.
Playback note: with preview off, the current step uses the main lane. Turn preview on to hear the authored fill lane on this track only.
Reset rule: changing the selected track or closing the editor returns the toggle to off.
Why this variant
Transient by placement The control sits next to Source / Modifiers instead of inside the phrase grid, which keeps it framed as session playback state.
Track scoped The active track in the left list owns the toggle state; sibling tracks never show as forced on.
Generator-safe Generator tracks switch to a disabled button with an explanatory message instead of pretending fill works there.
