This version keeps the control close to the lane chips, which may help discoverability but risks feeling like an authoring toggle instead of live playback state.
With preview off, playback follows the compiled phrase path. Turning it on temporarily forces the selected track to hear its fill lane.
Switching tracks clears the preview so the editor never carries a hidden forced-fill state across selections.
Tradeoffs
More discoverable near the lane tabs Users already look here while editing normal versus fill content, so the toggle is hard to miss.
Higher confusion risk Because the control sits beside lane authoring tabs, some reviewers may read it as a data edit rather than a transport-affecting preview.
Generator fallback still explicit The same control can collapse into a disabled pill with a scope note when the track uses a generator source.
