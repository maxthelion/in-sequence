# Perform Mode, Phrases, Layers, And Capture

Exploratory wireframes for a richer perform-mode information architecture:

- phrase-aware transport and cueing;
- layer changes across selected tracks;
- layer-perform matrix across tracks;
- track/drum-group perform detail;
- capture clip and capture phrase flows.
