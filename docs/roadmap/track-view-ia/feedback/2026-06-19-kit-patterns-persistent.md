# Kit Patterns Always Visible; Capture + Perform In The Header

Raw product-owner clarification:

> The patterns on the kit page should always be visible, and be above the tabs.
> Let's put a capture button to open the history next to the perform button above
> that. It can replace the tab view, but keep the patterns for assigning.

Interpretation for build:

- The kit **Patterns row** (group pattern slots + link control) is **always
  visible, above the kit tab bar** — a persistent assignment surface.
- **Capture** and **Perform** are **header buttons** (not tabs), side by side,
  above the patterns.
- **Capture opens the history surface**, which **replaces the tab view**; the
  Patterns row stays visible so a captured clip set can be assigned to a slot.
- History is therefore reached as a capture action, not a persistent tab.
