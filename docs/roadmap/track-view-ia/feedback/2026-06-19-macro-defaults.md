# Macros As A Tab, With Editable Type Defaults

Raw product-owner clarification:

> we might want to create defaults for the macros, for example, for drum parts,
> with things like sample direction, sample length, filter cutoff as initial
> values.

Interpretation for build:

- Macros are a **first-class tab** (per track and per kit): macro lanes + slot
  assignments (M1–M8) together.
- Ship **editable templates seeded with initial values** per track type: a fresh
  **drum part** lands with M1 sample direction, M2 sample length, M3 filter
  cutoff pre-mapped. A **kit macro** template seeds cutoff-across-parts + bus
  drive.
- Defaults are **fully editable / removable** — initial values from a template,
  not fixed mappings.
