# Scoped Track Perform Reuses The Phrase Perform UI

Raw product-owner clarification:

> there should be an option for going to track perform as a button on a track or
> a drum kit page that goes into the new stuff that we did for the phrase views,
> but with the single track selected.

Interpretation for build:

- A **Perform** button on a track or kit opens the **phrase-style perform UI
  scoped down** to that single track / whole kit (not the project).
- **Reuse** the phrase perform grammar (layers, value cells, Mom/Latch gate,
  latch timing, Capture/Discard, basis phrase) — **no bespoke surface**.
- Kit scope performs the kit as one unit (linked); an unlinked kit can expose
  per-part rows.
