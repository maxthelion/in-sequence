⚠ Reviewer annotations — not part of the UI
  • (a) Closed: the dice button is its own row, directly above the pattern selector, per the owner's words. It uses the solid .btn-dice action grammar — never the pill/segment grammar of the tabs or Lane/Layer/Length below — so it never reads as a mode switcher. Slot 4 (active) has never been randomized, so the button and slot show no persisted-dot; jump to rolled to see the dot appear on both once settings exist.
  • Per-clip relationship: slot 7 already carries persisted randomize settings from an earlier session (small accent ring at its corner) — a second, non-active example, proving the indicator is per-clip, not global/active-only.
  • (b) Settings surface: built as the shared StudioModal sheet (matches 02c-create-track-modal.png: dimmed backdrop, centered card, title + accent dash, circled close) rather than a bespoke popover — the repo has no popover primitive, and six rule groups + audition + undo match the weight of existing sheets (RouteEditorSheet, PhraseCellEditorSheet), not a lightweight anchored menu.
  • Continuous vs. discrete rules: Density, Velocity Variance, Gate Variance, Octave Center/Span are rotary knobs per canon Rule 6 (no slider thumbs). Scale and Root are discrete choices, rendered as inset-track solid-thumb chips per the D-grammar's value-selector rule (never the tab-pill grammar).
  • Octave affordance: the highlighted band over the octave strip visualises center ± span directly — this is the "ties into the octave intent" requirement, communicated by the band's position/width rather than a caption.
  • Auditioning: pressing Re-Roll fills the audition strip and raises a green "Playing" pill (canon Rule 11 live-green class) with a playhead ring on the currently-sounding step — the affordance for "hear it play" without simulating real playback timing in a static prototype.
  • Undo: disabled/dashed until a roll has happened in this sheet session, then becomes a solid accent icon button. No confirmation sentence for the destructive overwrite — the control's own state change is the warning + the escape hatch.
  • (c) Result: closing the sheet after a roll bakes the data into the main Steps/Clip well — the plain on/off grid is replaced by a pitch-labelled grid (note name above each active step), and the persisted-dot now lights on both the dice button and pattern slot 4.
