Reviewer annotations — not part of the design
  • Header hoist: the amber FOLLOWING chip and the Bake-to-clip action (the bake/randomize primitive from 20260702-150003-clip-randomize-baked.md / the pipeline synthesis's bake(source + seed) -> clip) now live in the generator header, visible from Trigger or Pitch — the thing 14(c)'s unified surface was solving, without merging the stages.
  • Result strip: always shows resolved trigger + pitch, independent of which stage tab is open — the split editor's one weakness, fixed structurally instead of by unifying.
  • Stage switcher: deliberately the inset-track solid-thumb grammar (value-selector family, same as Mode/Lane/Layer chips), not the D-pill grammar — this editor is already content inside the track's own Steps/Clip D-pill + well, so a second pill row here would read as a sibling section rather than a subordinate switch.
  • Cluster: bipolar, center-zero rotary (top-arc dial, zero tick at 12 o'clock) shared with the future density transform's placement character; R/A end glyphs light up solid on whichever side the value leans.
  • Chord filter semantics: the "Pool filter only" chip next to Chord Source states the 2026-07-03 correction directly — the sidechain filters available pitches, it is never a trigger input, so it has no presence in the Trigger stage at all.
  • Result-strip flags (state b): a small ring badge at a step's top-left marks an accidental (out-of-pool tone let through by the Accidentals deviation knob); top-right marks an octave jump (register change let through by Octave ±). Shape only, no caption.
  • Weighted trigger source and the Cluster/Deviation families do not exist in StepAlgo/PitchAlgoEditor yet — proposal only, per the pipeline synthesis's generator vocabulary section.
