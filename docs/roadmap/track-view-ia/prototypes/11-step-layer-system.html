Reviewer annotations (not part of the surface)
  • Pitch cell: scale degree is the dominant glyph (large, centered — e.g. "1", "5", "♭3" for a chromatic passing tone); octave is a separate 3-dot band along the bottom edge (Low/Mid/High register at a glance), with a small corner badge ("+2"/"−2") only when a step sits outside that immediate band. Dots are click targets so octave is shiftable directly on the cell, no separate control.
  • Off steps render identically across every layer (empty ring cell) — Velocity/Chance/Gate/Pitch only carry data where Steps has a note, so switching layers never desyncs which columns are "on".
  • Cell grammar by data shape: binary (Steps) = solid fill, no glyph. Continuous magnitude (Velocity, Chance, Gate) = bar rising inside an outlined cell. Discrete value (Pitch degree, Slice Index, Direction, Note Repeat) = solid fill + centered glyph. Same component family reused across both track types — proves one grid grammar.
  • Quick-switch closed: a solid accent value-chip showing only the current layer's abbreviation — same "small elements go fully solid" rule as any other value chip (canon Rule 12). No separate label duplicating "Layer" next to it.
  • Quick-switch open: a compact square matrix (not a literal 8×8 — sized to the layer count, 3 cols here) sunk in the same darker inset track used by every other value selector, echoing the phrase-view Layers grid the owner referenced. Each cell shows its own layer name plus a small "has content" dot (green = edited, grey = default) — no restated header text. Selecting a cell both switches the layer and closes the panel.
  • Unused capacity: mono's 5-layer set leaves one matrix cell as a dashed stub (reserved, non-interactive) rather than resizing the grid — keeps the matrix shape stable as layers are added (e.g. a future Modulation layer) instead of reflowing per track type.
