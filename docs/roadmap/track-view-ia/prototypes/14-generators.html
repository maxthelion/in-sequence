Reviewer annotations — not part of the design
  • Amber marks the chord generator's identity (well outline in (a), content-accent chips/values wherever a chord source is referenced in (a-2)/(b)/(c)) — never used as a container fill, per canon Rule 12.
  • Chord Source row replaces PitchAlgoEditor's current Picker("Harmonic Sidechain", …) (a plain dropdown menu today) with the same inset-track chip grammar used for every other value selector, so the sidechain relationship is visible without opening a menu.
  • Weighted trigger mode does not exist in StepAlgo yet (only .euclidean) — the bar treatment reuses the existing GridEditor component already shipped for pitch-stage degree weights (PitchAlgoEditor.intervalProb).
  • (b) and (c) carry identical params (Euclidean/Weighted trigger, Markov/Scale pitch, Chord Source) so the split-vs-unified comparison is structural only, not a difference in capability.
  • Dashed boxes are off-path stubs (Sound/FX/Macros/Mixer, and the sidechain surface's own Trigger pane, which is fully shown in (b) instead).
