Story 5 — Page navigation arrows at matrix corners

Arrows are positioned in the two corner cells of the matrix header row — 32 px wide each — flanking the track-name cells. An occupancy badge shows how many tracks are on the adjacent page (or the arrow is greyed/hidden when no adjacent page exists).

Layout constraint: The 32 px nav-arrow corner cells are shared between stories 5 and 6. The layer bar uses the same 3-column grid (32px 1fr 32px) so the selector naturally aligns with the track-name and step-cell columns. The 220 px fixed width should be validated against the smallest device width — on narrow layouts the selector text will truncate (ellipsis) rather than expand the container.
