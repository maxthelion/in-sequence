# Test fixtures

Loadable `.seqai` project documents for manual/real-audio testing, generated by
programmatic builders so they stay valid as the model evolves.

## audio-rich-routing.seqai

A representative project exercising every sound-producing destination kind plus
the send/mixer-bus routing topology — built for the **audio-routing-cleanup
real-audio pass** (`docs/human-attention/verify-audio-routing-cleanup-branch.md`).

Built by `Sources/App/AudioRichFixture.makeProject()` (deterministic, fixed
UUIDs). Regenerate / round-trip-check via
`Tests/SequencerAITests/App/AudioRichFixtureTests.swift`.

Contents:
- **Analog Lab Lead** — mono melodic track → **Arturia Analog Lab V** AU
  instrument (`aumu/Alav/Artu`). Routed to **Send A** at 0.6.
- **Audio Rich Fixture Loop** — slice track over a generated 8-burst sample.
  Routed to **Send B** at 0.5. (See materialization note below.)
- **Audio Rich Kit** — a drum group (Kick/Snare/Hat/Clap), each part on the
  Apple internal sampler (`.drumKitDefault`) — guaranteed sound, no third-party
  AU. Kick routed to the **FX Bus** mixer bus, four-on-the-floor.
- **FX Bus** mixer bus; **Send A** and **Send B** each with a native low-pass
  filter insert.
- No AIR Music Technology AUs (expired licenses) are referenced anywhere.

### Loading it
Launch the built app pointed at the fixture (env var consumed by
`VisualFixtureDocumentLoader`):

```
SEQUENCER_AI_NEW_DOCUMENT_FIXTURE=docs/fixtures/audio-rich-routing.seqai \
  <DerivedData>/Build/Products/Debug/SequencerAI.app/Contents/MacOS/SequencerAI
```

or open the `.seqai` from the app.

### Slicer sound — materialization note
The slice track references a WAV at `breaks/audio-rich-fixture-loop.wav` in the
AudioSampleLibrary tree; `makeProject()` does NOT write it (keeps the builder
pure). The slice track will be **silent until the WAV is materialized** via
`AudioRichFixture.materializeSlicerSample()`. The **AU mono track and the drum
kit make sound without any materialization**, and they already exercise both
sends + the mixer bus — so the routing pass is fully doable even if the slicer
is silent. (Wiring auto-materialization on fixture load is a small follow-up if
the slicer's sound is wanted in the pass.)
